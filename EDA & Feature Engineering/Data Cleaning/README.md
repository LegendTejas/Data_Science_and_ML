# Data Cleaning

Data cleaning is the process of detecting and correcting errors, inconsistencies, and inaccuracies in a dataset so that the data becomes reliable for analysis or machine learning.

Real-world data is rarely perfect. It may contain:

- Missing values
- Duplicate records
-Incorrect data types
- Inconsistent formatting
- Invalid values
- Outliers

If these issues are not handled properly, the model may learn incorrect patterns. This section will cover all the Data Cleaning Methods
